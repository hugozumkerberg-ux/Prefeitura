ARQUITETURA DE SISTEMAS & PRODUTO

Como os Dados Coletados Vão Alimentar o Nosso Novo Site

Entenda o ciclo de vida completo: desde a raspagem nos servidores antigos da prefeitura até a disponibilização em uma interface moderna, auditável e 100x mais rápida para o cidadão e para os órgãos de controle.

O Salto Tecnológico: Como é Hoje vs. O Nosso Novo Portal

O Portal Atual (ADPMNET / Prefeitura)

  • Lento e instável (frequentemente com tela branca ou travamento).
  • Obriga o usuário a saber ano, mês e formulário para achar qualquer coisa.
  • Não tem busca global por nome de servidor ou fornecedor.
  • Dados espalhados em dezenas de tabelas HTML e PDFs isolados.
  • Não mostra gráficos, evolução salarial ou históricos de viagem.

O Nosso Novo Portal da Transparência

  • Respostas instantâneas (< 50 milissegundos) com banco local SQLite/Postgres.
  • Busca universal estilo Google: digite um nome ou CPF e veja o histórico de 2013 a 2026.
  • Auditoria com 1 clique: botão que mostra a URL oficial e o hash SHA-256 de prova.
  • Visualização de holerites completos com discriminação de cada desconto e gratificação.
  • Gráficos interativos de evolução salarial, fornecedores e gastos por secretaria.
O Fluxo de Engenharia de Dados (Pipeline ETL)

O pipeline transforma dados públicos caóticos e espalhados em uma base de dados relacional pericial e de altíssimo desempenho:

01

Ingestão Probatória & Coleta Retroativa

O motor acessa os formulários da prefeitura e fundação (tpformpdf 51, 52, 56, 59), inicia no mês atual e recua até encontrar 30 vazios. Salva o HTML/CSV intacto na pasta dados/auditoria/raw/ e gera o hash SHA-256.

Entrada: HTTP / ADPMNET
Saída: HTML bruto + SHA-256
Garantia: Prova Jurídica
02

Extração, Higienização e Parser Estruturado

O script lê os HTMLs brutos salvos e extrai os campos: número do empenho, fornecedor, CPF/CNPJ, cargo do servidor, salário base, vantagens, descontos, motivo das diárias e dotação orçamentária.

Parser: Regex + Cheerio/DOM
Normalização: Reais (R$), CPFs
Descarte: Células nulas/órfãs
03

Banco Relacional & Índices de Busca Instantânea

Os dados limpos são persistidos em tabelas relacionais com índices em Nome, CPF/CNPJ, Ano/Mês e Valor. Isso permite buscar entre mais de 180 mil linhas em milissegundos.

Storage: SQLite / WAL Mode
Índices: B-Tree + FTS5 Full-Text
Velocidade: < 5ms por consulta
04

Camada de API REST Ultraleve

Um servidor leve em Node.js (Fastify ou Express) entrega os dados em JSON para o frontend com rotas simples e protegidas: /api/servidores, /api/contracheques, /api/despesas e /api/diarias.

API Engine: Fastify / Node.js
Formato: JSON comprimido
Cache: Memória / ETag
05

Frontend do Novo Portal da Transparência

Interface moderna construída para o cidadão e auditores, com busca estilo Google, filtros por cargo/secretaria, gráficos de barras de salários, painel de fornecedores e botão de contraprova oficial.

Frontend: HTML5 + Tailwind + Vue
Gráficos: Chart.js / SVG
Exportação: PDF e Excel/CSV
